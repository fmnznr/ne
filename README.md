# Hmpf und das Kritzelherz

Ein kleines Point-and-Click-Adventure im Kugelschreiber-Look, nach einer Notizbuch-Zeichnung von **ne** (`zeichnung.jpg`).

Hmpfs Herz wurde zugekritzelt. Gerda (Spirale oder Schnecke), ein Esel im Eselsohr, ein Kassenbon und viel Hüpfen helfen, es wieder zum Schlagen zu bringen.

## Spielen

`index.html` im Browser öffnen (eine Datei, keine Abhängigkeiten außer Google Fonts).
Lokal mit Bild: `python3 -m http.server` im Ordner starten und `http://localhost:8000` aufrufen.

- Auf Dinge tippen: Ansehen, Nehmen, Benutzen, Reden
- Auf Hmpf tippen: Nahaufnahme
- Gegenstände im Bauch auswählen und auf etwas anwenden (auch Gegenstände miteinander)
- „Tipp“ oben hilft weiter; der Spielstand wird im Browser gespeichert
